# 3팀 쿼터 점수판

로그인 없이, 링크만 있으면 여럿이 같이 보고 입력하는 실시간 점수판이에요.
외부 라이브러리 없이 Node.js 서버 하나(`server.js`)와 화면 파일 하나(`public/index.html`)로 돼 있어요.

## 어떻게 쓰나요

1. 사이트에 들어가서 **새 게임 만들기**를 누르면 방이 생기고 링크(방 코드)가 나와요.
2. 팀 이름, 경기 순서, 1쿼터 선공을 정하고 **시작하기**를 눌러요.
3. 링크를 받은 사람은 누구나 같은 화면을 보고, 점수를 입력할 수 있어요. 한 사람이 입력하면 모두의 화면이 바로 바뀌어요.
4. 구경만 할 사람에게는 **보기 전용 링크 복사**로 만든 링크를 주세요.

점수는 `10 9`처럼 숫자 두 개로 입력해요. 화면에서 왼쪽에 보이는 팀 점수를 먼저, 오른쪽 팀 점수를 나중에 적어요.
같은 두 팀이 다시 붙을 때는 직전에 선공이 아니었던 팀이 선공이에요.

설정에서 팀 이름, 팀 색(8가지 중 선택)을 정할 수 있어요. 색은 점수판 곳곳의 팀 이름 옆 점과 점수 입력 카드 위쪽 띠에 나와요.

앱 로고는 방 화면의 **로고 올리기**로 우리 모임 사진으로 바꿀 수 있어요(사진 가운데를 정사각형으로 잘라 써요). 점수판 맨 위 로고와 홈 화면 앱 아이콘이 그 사진으로 바뀌고, **기본으로**를 누르면 되돌아가요. 로고는 방마다 따로 저장돼요.

설정에서 경기마다 1쿼터에 코트 왼쪽에 서는 팀을 정해요. 1·2쿼터는 그대로, 3쿼터부터는 코트 체인지로 왼쪽과 오른쪽이 바뀌고 화면에 안내가 나와요.
입력한 점수는 팀 기준으로 저장돼서, 좌우가 바뀌어도 어느 팀 점수인지 헷갈리지 않아요. 아래 쿼터별 표는 팀 이름 순서(앞 팀 : 뒤 팀)로 보여줘요.

## 인터넷에 올리기 (Render 무료 서버)

처음 한 번만 하면 돼요. 아래 화면 문구는 서비스가 바뀌면 조금 다를 수 있어요.

### 1. GitHub에 코드 올리기

1. [github.com](https://github.com)에 가입하고 로그인해요.
2. 오른쪽 위 `+` → **New repository**를 눌러요. 이름은 `quarter-board`처럼 아무거나 괜찮아요. 공개(Public) 또는 비공개(Private) 둘 다 돼요. **Create repository**를 눌러요.
3. 만든 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. 이 zip을 먼저 풀고, 풀린 폴더 안의 파일 전체(`server.js`, `package.json`, `render.yaml`, `README.md`, `public` 폴더)를 끌어다 놓아요. `public` 폴더째로 올려야 해요.
5. 아래쪽 **Commit changes**를 눌러요.

### 2. Render에서 서버 켜기

1. [render.com](https://render.com)에 GitHub 계정으로 가입해요.
2. 대시보드에서 **New +** → **Blueprint**를 골라요. 방금 만든 저장소를 연결하면 `render.yaml`을 읽어서 설정을 채워 줘요. **Apply** 또는 **Deploy**를 눌러요.
3. (Blueprint가 잘 안 되면) **New +** → **Web Service**로 저장소를 고르고 이렇게 채워요.
   - Runtime: `Node`
   - Build Command: 비워 두거나 `echo no build`
   - Start Command: `node server.js`
   - Instance Type: `Free`
4. 몇 분 뒤 `https://이름.onrender.com` 주소가 생겨요. 들어가서 **새 게임 만들기**를 눌러 보면 끝이에요.

## 폰에 앱처럼 설치하기 (무료, 스토어 필요 없음)

방에 들어간 상태에서 아래처럼 하면 홈 화면에 아이콘이 생기고, 주소창 없이 앱처럼 열려요. 아이콘을 누르면 그 방이 바로 열려요.

- 아이폰(Safari): 아래쪽 공유 버튼 → **홈 화면에 추가** → 추가
- 안드로이드(Chrome): 오른쪽 위 메뉴(점 세 개) → **앱 설치** 또는 **홈 화면에 추가**

방마다 아이콘이 따로 만들어져요. 아이콘은 설치한 방의 주소로 열려요. 매주 같은 모임이라면 방을 새로 만들지 말고, 같은 방에서 오른쪽 위 **새 게임**을 눌러 점수만 비우고 계속 쓰세요. 그러면 설치한 앱을 다시 만들 필요가 없어요.

## 무료 서버라서 알아 둘 점

- 15분 동안 아무 요청이 없으면 서버가 잠들고, 다시 깨우는 데 1분쯤 걸려요. 점수판 화면이 열려 있는 동안은 몇 분마다 가벼운 요청을 보내서 잠들지 않게 해 뒀어요.
- 무료 서버는 아무 때나 재시작될 수 있고, 그러면 서버에 있던 방이 사라져요. 이때는 화면이 열려 있던 기기에 남은 마지막 점수로 방을 자동으로 되살려요. 화면을 모두 닫은 상태에서 재시작되면 서버는 되살릴 수 없지만, 앱을 열었던 적 있는 폰에는 마지막 상태가 남아 있어서 그 폰으로 방을 열면 팀 이름과 설정까지 다시 살아나요. 단, 올려 둔 로고 사진은 서버에만 있어서 다시 올려야 해요.
- 한 달 무료 사용 시간(750시간)이 있어요. 잠든 시간은 세지 않아요.

## 보안

- 방 코드나 링크를 아는 사람은 누구나 점수를 입력할 수 있어요. 로그인이 없는 대신 링크를 아는 사람만 들어오는 방식이에요.
- 보기 전용 링크는 입력창을 숨겨 줄 뿐이에요. 서버가 막아 주는 건 아니라서, 입력까지 막아야 하는 용도라면 쓰지 마세요.
- 방은 180일 동안 쓰지 않으면 지워져요.

## 내 컴퓨터에서 켜 보기

Node.js 18 이상이 설치돼 있으면 이 폴더에서 아래를 실행해요.

```
node server.js
```

브라우저에서 `http://localhost:3000`으로 열어요. 같은 와이파이의 폰에서는 `http://컴퓨터IP:3000`으로 열 수 있어요.

## 파일 구성

- `server.js`: 방 관리, 점수 검증, 실시간 전송(SSE), 파일 저장
- `public/index.html`: 화면 전체 (디자인과 동작)
- `public/sw.js`, `public/icon-*.png`, `public/apple-touch-icon.png`: 앱으로 설치하는 데 쓰는 파일
- `render.yaml`: Render 설정
- `package.json`: 실행 정보 (설치할 라이브러리 없음)
